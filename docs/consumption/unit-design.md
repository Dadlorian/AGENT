### The unit's lifecycle (adopted, not invented)

| State | The sketch's word | Meaning |
|---|---|---|
| submitted | declared / admitted | the envelope validated, the chain ran at admission, the contract digest is ledgered, nothing has been spent |
| working | seeded / attempting (n of N) | the cell is admitted and the harness is taking turns; attempts are counted outside the cell |
| input-required | (absent from the sketch) | the advisor parked an approval gate - the attempt ceiling fired, or an irreversible action was reached |
| auth-required | (absent from the sketch) | the broker cannot obtain a mandate for a declared egress destination |
| completed | done | measure returned passed on every deciding check; stop_reason end_turn |
| failed | exhausted | a cap fired: iteration ceiling, budget ceiling, deadline, cancel-grace expiry or adapter unavailability |
| rejected | refused | a chain slot refused before anything ran; stop_reason policy_denied |
| canceled | cancelled | cancellation accepted and a terminal frame arrived inside the grace window |
