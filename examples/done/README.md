# done — how I know, and what happens next

Four units finished. This example is the boundary that closes them: it reads
each check report and says on which rung of the ladder the unit stopped, seals
what each one leaves behind, attests it at the one boundary every producing path
passes through, appends the record to an append-only history that hands out
proofs, refuses to promote anything whose statement does not verify against the
bytes it has, promotes what passes as a branch or a pull request, tells the door
that asked, and leaves one receipt line carrying the cost.
`bash examples/done/test.sh` is the visible check.

Every row below is cited to a knowledge-base id, a research id, or a file with a
verbatim quote — each grepped back out of the record it names by `test.sh`
section 16 — or it says **proposed** and gives its reasoning. Product names
appear only in the standards table and the adapters table.

## 3. The call

All four doors enter through one shape:
`T-t6-02` "Four entries cover nearly every situation: a human, an event, a schedule (time), and an external system or agent."
Each document below validates against `examples/end-to-end/schemas/entry.schema.json`
with that example's own validator, and none of them names a signer, a key, a
store or an adapter:
`F-b1-05` "A caller needs no client library we wrote."

Measured, not asserted: the four doors seal the same four subjects at the same
digests and one run-output predicate with the same materials and code version,
while carrying four actors, four correlation ids and four notification surfaces,
and the entry envelope's own digest is a material of every **run-output**
statement, so no two doors produce the same one (`test.sh` section 1). The
metadata-light statements the same run writes through the wired boundary are the
other shape: one per attested record — seventeen over a pass of the four doors,
the sixteen units plus the review request the pull-request door seals — naming
the artifact and the actor, and neither the run nor the code version that
produced it (`test.sh` section 4, gap G15).

| # | Claim that is not supported here | Research query |
|---|---|---|
| G1 | The four units arrive finished: their attempts, costs, stop reasons and check reports are declared in the closure, so this example measures the closing boundary and not the work.
