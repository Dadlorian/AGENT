00 · Contract

Everything a second surface needs to feel like Cell-Plane.

Tokens for both themes, two typefaces and their roles, the state palette, the glyph set with one path per verb, the recovery-ladder model, every component with its measurements, the view inventory, motion budget, and the rules that keep it quiet. cellplane-tokens.css and cellplane-data.js are the machine-readable halves; this page is the human one.

Status is the primary axis

Sort, filter, colour by state first. Workflow second. Everything else is detail behind a tap.

One glyph per row

The suggested action, filled orange. All other valid actions live in the sheet with the same glyph beside the word.

Orange is the only attention hue

Stuck, blocked stage, primary action, "n need you". Selection is a text-coloured border, never a hue.

Self-healing is bounded and visible

Ladders run per problem type with a max per rung; exhausted tasks show the person glyph and wait for you.

04 · Action glyphs

Seventeen verbs, one 16×16 path each, 1.6 stroke, round caps

Drawn once in ICONS and used everywhere: rows, cards, the sheet, bulk bar, ledger, playbooks. Filled orange = suggested for this state. Outlined muted = valid alternative. Green outline = a ladder rung is handling it. Faint chevron = nothing to do; open for detail.

05 · Recovery ladders

What the platform tries before it asks you

{{ l.type }}

Rungs fire once per bound, are logged as actor ladder:<type/verb>, pass the same policy check as a user, and never spend past the budget ceiling except the single Extend rung. Each fix (yours or the ladder's) is scored resolved or recurred after --outcome-after-ticks. A human action resets the ladder. Ladders never edit a Task specification or the Evaluator criterion.

08 · Geometry, motion, rules

Measurements and the things we do not do

Radius
4 inset · 5 control · 6 card · 8 sheet (10 mobile) · 3 pill · 999 only for "n need you".
Heights
44 row and minimum hit target · 40 control · 36 header control · 30 chip · 28 row glyph · 32 mobile glyph · 46 sheet primary.
Spacing
16 page gutter · 8 between cards · 6 between chips · 12/14 card padding · 18 between sheet sections. Grids: auto-fill minmax(300px,1fr) tasks, 220 lenses, 200 stats.
Breakpoint
One, at 760px: side panel becomes bottom sheet, rows become cards, swipe gestures activate. Everything else reflows with horizontal scroll rows and auto-fill grids.
Motion
Sheet 220–280ms ease-out slide · toast 200ms · live dot 1.6s pulse · running stripe 1s linear · skeleton 1.4s shimmer. State changes snap. Nothing else animates.
Copy
Reasons are measured, not interpreted: "timed out 3× against 45s ceiling". Actions name their mechanism: "session/cancel", "fresh sandbox (microVM)". Toasts confirm counts. Vocabulary from the platform, verbatim: Task, Task specification, Evaluator, Ledger, ceiling, f-/i-/b-/cli-.
Never
Gradients · icons for status · emoji · a status shown twice on one card · colour as decoration · a labelled action button on a row · left-border accents on healthy items · shadows except sheet, bars and toasts.
