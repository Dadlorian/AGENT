# Archive

Frozen, byte-for-byte copies of the standards registry and journey data as they existed
immediately before the migration to the `standards/<id>/` folder structure.

- `standards.pre-migration.json` — copy of `docs/standards/standards.json`, sha256
  `942b554b6e0867061211ed931e8b77bad16b57e894d81493a60dda0845a7e439`.
- `journey.pre-migration.json` — copy of `docs/journey/journey.json`, sha256
  `e52d42d0d5d7596ebe30c0ffbdd5d0c9cd02019cee9d5c4d2ac7c61e39dcf279`.

These files are never edited. The originals at `docs/standards/standards.json` and
`docs/journey/journey.json` were left in place, unmodified, when this archive was made —
this folder is a redundant safety copy, not a replacement for them. If the originals are
ever removed as a later, separately-approved cleanup, these archived copies remain the
citable record of what the registry looked like before the `standards/` folder structure
existed.
